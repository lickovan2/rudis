# RUdis

Русский аналог Discord: серверы, текстовые и голосовые каналы, личные сообщения, друзья, файлы и реакции. Интерфейс полностью на русском. Есть веб-версия и десктоп-клиент для Windows.

## Что умеет

- **Серверы**: создание, иконка, приглашения по ссылке, роли «владелец / администратор / участник», исключение участников.
- **Текстовые каналы**: сообщения в реальном времени, ответы, редактирование и удаление, реакции, «печатает…», непрочитанные, упоминания `@логин`.
- **Разметка**: `**жирный**`, `*курсив*`, `__подчёркнутый__`, `~~зачёркнутый~~`, `||спойлер||`, `` `код` ``, блоки ```` ``` ````, `> цитаты`, ссылки.
- **Файлы**: вложения до 25 МБ (кнопка, вставка из буфера, перетаскивание), превью картинок, видео и аудио.
- **Голосовые каналы**: WebRTC, индикатор говорящего, выключение микрофона и звука, громкость каждого участника, выбор микрофона и динамиков.
- **Друзья и ЛС**: заявки по логину, статусы «в сети / не в сети», личные переписки, уведомления.
- **Десктоп**: Electron-клиент с выбором адреса сервера, счётчиком непрочитанных и доступом к микрофону.

## Запуск для разработки

Нужен Node.js 24+.

```bash
npm install
npm run dev        # сервер на :3001 + веб на http://localhost:5173
```

Откройте http://localhost:5173, зарегистрируйтесь, создайте сервер и позовите друга ссылкой-приглашением.

Десктоп-клиент в режиме разработки:

```bash
RUDIS_URL=http://localhost:5173 npm run desktop
```

## Продакшен-сборка

```bash
npm run build      # собирает web/dist
npm start          # сервер отдаёт API, WebSocket и собранный фронт на :3001
```

Портативный exe для Windows:

```bash
npm run dist -w desktop   # desktop/dist/RUdis-<версия>-portable.exe
```

При первом запуске клиент подключается к `http://localhost:3001`. Адрес сервера меняется через меню «RUdis → Сменить сервер…».

## Настройки сервера (переменные окружения)

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `3001` | Порт HTTP и WebSocket |
| `JWT_SECRET` | dev-значение | **Обязательно поменять в продакшене** |
| `DATA_DIR` | `./data` | База SQLite и загруженные файлы |
| `TURN_URL`, `TURN_USER`, `TURN_PASS` | — | Свой TURN-сервер (coturn) для голоса через сложные NAT |

## Голос: как устроен и ограничения

Голос работает по схеме P2P-mesh: каждый участник соединён с каждым напрямую, а сервер только пересылает сигналинг. Это не требует медиасервера и хорошо работает примерно до 6–8 человек в канале. Для больших каналов следующий шаг — SFU (LiveKit или mediasoup).

Для голоса между разными сетями нужен TURN-сервер, иначе часть пользователей за строгим NAT не соединится. Браузер пускает к микрофону только на `https://` или `localhost`, поэтому в продакшене нужен TLS (nginx + Let's Encrypt).

## Структура

```
server/src/
  index.ts        точка входа, статика, обработка ошибок
  db.ts           схема SQLite и хелперы
  access.ts       права доступа и сериализация
  realtime.ts     Socket.IO: события, присутствие, сигналинг голоса
  routes/         auth, servers, messages, social (друзья и ЛС), uploads, voice
web/src/
  store.ts        состояние приложения и обработка событий сокета
  voice.ts        WebRTC-клиент голосовых каналов
  ui/             компоненты интерфейса
desktop/          Electron-клиент
scripts/smoke.mjs сквозной тест
```
